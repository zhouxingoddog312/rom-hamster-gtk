## 结论

- 10k 整表刷新约 82–86 ms，查询耗时不是瓶颈；详情元数据约 5 ms、首张缩略图约 80 ms，均明显低于阈值。
- 关键字筛选的**纯查询**约 30–55 ms；100 ms 防抖叠加后总时延约 128 ms，按“输入停顿到模型更新完成”的严格口径达标。
- 冷启动、详情、内存增长达标；首屏与滚动帧率在本机软件渲染下超阈值，且 3 行夹具首屏也约 690 ms，说明该数字主要反映 WSLg/Xvfb 首次渲染，不是 10k 数据量本身。参考机型复测前不据此判定发布阻断。
- 缩略图磁盘缓存已实测：详情页冷启动 `cache_hits=0`、`thumb_load_ms≈63 ms`；同一 `XDG_CACHE_HOME` 热启动 `cache_hits=1`、`thumb_load_ms≈25 ms`。`first_thumb_ms` 含 UI 调度噪声，只看 `cache_hit` 与 `thumb_load_ms`。缓存默认 256 MiB，按 mtime LRU 淘汰；`tools/m4-cache-check.sh` 用 2 MiB 上限验证从 5124 KB 降到 1032 KB。
- 导入进度/取消两项已在独立 800 / 1500 文件夹具上实测：进度回调最大间隔 38.5 / 83.7 ms，UI 刷新最大间隔 117.9 / 172.0 ms，取消到线程退出 3–4 ms。该夹具不是 10k 整库导入；10k 单 ROM 整库导入另测：CLI 3 轮中位 27.69 s（361.1 games/s），maxRSS 20216 KB，见上一节。
